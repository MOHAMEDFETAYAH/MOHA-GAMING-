# MOHA GAMING

موقع عربي متوافق مع الهاتف لعرض مكتبة ألعاب وثيمات PS3. يعمل كصفحة ثابتة ويمكن نشره مجانًا عبر GitHub Pages.

## الملفات
- `index.html` — محتوى الصفحة.
- `style.css` — التصميم والألوان والتجاوب مع الهاتف.
- `script.js` — عناصر المكتبة والبحث والتصفية وروابطها.

## تعديل الألعاب والثيمات
افتح `script.js` وابحث عن `const items = [` ثم عدّل العناصر:
- `title`: اسم اللعبة أو الثيم.
- `type`: اكتب `game` للعبة أو `theme` للثيم.
- `subtitle` و`detail`: الوصف.
- `symbol`: النص الظاهر على بطاقة الغلاف.
- `color`: ألوان الغلاف.
- `size`: الحجم أو صيغة الملف.
- `url`: رابط يبدأ بـ `https://` لملف يسمح لك صاحبه بإعادة توزيعه. اتركه فارغًا إذا لم يكن لديك رابط.

لا تضع ملفات ألعاب أو محتوى محمي بحقوق النشر ما لم تكن تملك الحق القانوني في توزيعه.

## النشر من هاتف Android
1. أنشئ حسابًا على https://github.com/ .
2. اضغط علامة `+` ثم **New repository**.
3. سمّ المستودع `moha-gaming` واختر **Public** ثم **Create repository**.
4. داخل المستودع اضغط **Add file** ثم **Upload files**، وارفع الملفات الثلاثة: `index.html` و`style.css` و`script.js` (يمكنك فك ملف ZIP على الهاتف أولًا).
5. اضغط **Commit changes** لحفظ الملفات.
6. افتح **Settings** للمستودع، ثم **Pages**.
7. ضمن **Build and deployment** اختر **Deploy from a branch**.
8. اختر الفرع `main` والمجلد `/(root)` ثم اضغط **Save**.
9. انتظر قليلًا، ثم افتح رابط الموقع الذي يظهر في صفحة Pages. غالبًا يكون بالشكل:
   `https://YOUR-USERNAME.github.io/moha-gaming/`

قد تستغرق أول عملية نشر عدة دقائق. إذا لم يظهر الرابط مباشرة، حدّث صفحة Pages بعد قليل.

## تنبيه
الرابط أعلاه قالب فقط؛ استبدل `YOUR-USERNAME` باسم حساب GitHub الحقيقي. GitHub Pages يستضيف الملفات الثابتة ولا يشغّل خادمًا خلفيًا.
